# Diana Ferreira

Synthetic Patient Summary derived from the Diana Ferreira CDA example and later
reworked for EHDS, IPS, EU-EPS, CTS, and NMPC review.

## Canonical Bundles

- `fhir/ehds-aligned/bundle.json`: rich EHDS-aligned review bundle.
- `fhir/ips-gazelle/bundle.json`: IPS Gazelle validator-facing bundle.
- `fhir/eu-eps-gazelle/bundle.json`: EU-EPS Gazelle validator-facing bundle.
